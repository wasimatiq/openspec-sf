# Security Policy

## Supported Versions

This project does not yet have tagged releases. Security fixes are applied to
the `main` branch.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately rather
than opening a public issue.

- Preferred: use [GitHub's private vulnerability reporting](https://github.com/wasimatiq/openspec-sf/security/advisories/new) for this repository.
- Alternatively, email wasimatiq@gmail.com with details.

Please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce, or a proof of concept.
- Any suggested remediation, if known.

You should expect an initial response within a few days. Once a fix is
available, a security advisory will be published and credit given to the
reporter, unless anonymity is requested.

Please do not disclose the issue publicly until it has been addressed.
